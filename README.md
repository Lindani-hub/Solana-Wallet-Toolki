
# Solana Wallet Toolkit

A beginner-friendly Web3 project for checking public wallet balances on Solana Devnet.

## Features

- Check a public Solana address balance
- Display SOL balance in a clean interface
- Open the address in Solana Explorer
- No wallet connection or private key required
- Responsive design for mobile devices

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Solana JSON-RPC API

## Getting Started

1. Open `index.html` in a browser, or deploy the
   repository using GitHub Pages.
2. Paste a public Solana wallet address.
3. Select "Check Devnet Balance".

## Network

This project uses Solana Devnet.
Devnet SOL is for testing and has no mainnet value.

## Security

Never share your seed phrase or private key.
This application does not request either.

## Limitations

The app depends on public RPC availability and rate limits.
Basic address-format checking is not full cryptographic validation.
